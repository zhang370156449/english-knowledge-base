# 📚 LexiFragment | 英语碎片化知识库

> 极简、高质感、现代化的个人英语碎片化知识库。融合 Anthropic Claude 经典设计美学（陶土暖褐与黑曜灰质感），提供沉浸式短视频剧场播放、精选文章与原版书籍研读体验。

---

## ✨ 核心特性

- **🎬 沉浸式知识剧场**：支持短视频全景悬浮播放、键盘快捷键操控（ESC 退出、空格暂停/播放）、进度记忆与高光复习。
- **🏷️ 词根与高频词眼聚光灯**：每条短视频均提炼核心词根/词眼（如 `over`、`rupt`、`pose`、`tract` 等），一目了然。
- **📖 预留文章与原版书扩展**：深度支持 Markdown 渲染，内置排版规范与元数据同步系统。
- **⚡ 一键库同步 (`sync_library.bat`)**：本地新增视频文件夹或 Markdown 笔记后，一键自动补全封面缩略图并更新索引数据库。
- **📱 响应式全平台适配**：手机端、平板端、电脑端网页自适应布局，支持随时随地在线翻阅。

---

## 🚀 本地运行

双击根目录下的 `start_server.bat`，即可自动启动本地静态服务器并在浏览器中打开知识库。

## 🔄 同步与扩展内容

1. **新增视频**：在根目录下创建作者文件夹（如 `某某英语`），将 `.mp4` 放入其中。
2. **新增文章/书籍**：在 `articles/` 或 `books/` 目录下根据 `_template.md` 编写 Markdown 文件。
3. **一键同步**：双击运行 `sync_library.bat`，脚本将自动截取视频高清封面并刷新 `data.js`。
